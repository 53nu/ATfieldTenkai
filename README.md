# ATfieldTenkai

A TouchDesigner project inspired by the iconic "AT Field" effect from *Neon Genesis Evangelion*.

## Overview
ATfieldTenkai is a fan-made visual project created in TouchDesigner, exploring the look and feel of the AT Field effect.

## Download
The final project file (`.toe`) is available in the **Releases** section of this repository.

## Requirements
- TouchDesigner
- Compatible environment for running `.toe` project files

## Notes
- Unofficial fan-made project
